# Советник на hoster.kz — установка

Дашборд (officeweglow.kz, GitHub Pages) не умеет хранить секреты, поэтому ключ
DeepSeek живёт на обычном PHP-хостинге в одном файле `advice.php`. Дашборд
шлёт ему уже посчитанные метрики, скрипт спрашивает DeepSeek и отдаёт
рекомендации всем пользователям. Нужен PHP 7.4+ с curl — это есть на любом
тарифе hoster.kz.

## Шаги

1. **Загрузить файлы** через файловый менеджер панели хостинга или FTP в папку
   сайта (обычно `public_html/`; можно в подпапку, например `public_html/api/`):
   - `advice.php`
   - `.htaccess`

2. **Ключ.** Скопируйте `advice-config.example.php` в `advice-config.php`,
   впишите ключ DeepSeek и загрузите его **на уровень выше папки сайта**
   (рядом с `public_html`, там его не отдаст веб-сервер). Если панель не даёт
   писать выше `public_html`, положите рядом с `advice.php`: доступ к файлу
   закрывает `.htaccess`, а PHP-файлы сервер и так не показывает как текст.

3. **Проверка.** Откройте в браузере
   `https://ваш-домен/advice.php?selftest=1` (или `/api/advice.php?selftest=1`).
   Должно быть `"ok": true`, `"key_configured": true`, `"curl": true`,
   `"cache_dir_writable": true`. Если `cache_dir_writable: false`, дайте папке
   права на запись (755/775) или создайте рядом папку `advice-cache`.

4. **Домен.** Нужен HTTPS (дашборд открыт по HTTPS, браузер не пустит запрос
   на http). На hoster.kz SSL Let's Encrypt включается в панели одной кнопкой.
   Удобный вариант: поддомен `api.officeweglow.kz` → A-запись на IP хостинга,
   сайт-алиас в панели, SSL. Подойдёт и любой другой ваш домен на хостинге.

5. **Подключить дашборд.** В `dashboard.html` в константу `ADVICE_URL`
   вписать адрес, например `https://api.officeweglow.kz/advice.php`, и
   запушить. С этого момента советник работает у всех, кто открывает дашборд.

## Как это защищено

- Ключ в браузер не попадает, в репозиторий тоже (`advice-config.php` в
  `.gitignore`).
- Скрипт принимает запросы только с `officeweglow.kz` (Origin/Referer).
- Один и тот же набор метрик 30 минут отвечается из кэша без обращения к
  DeepSeek, поэтому клики по фильтрам почти ничего не стоят.
- Лимиты: 12 запросов с одного IP за 10 минут, 60 в час, 400 в сутки
  (меняются в `advice-config.php`). При превышении дашборд покажет
  «лимит исчерпан», а баланс не пострадает.

## Если что-то не так

- `403 запросы принимаются только с дашборда` — открыли адрес напрямую или
  с другого домена; добавьте домен в `allowed_origins`.
- `503 на сервере не задан ключ` — не найден `advice-config.php`
  или в нём пустой `deepseek_key`.
- `502 нет связи с DeepSeek` — хостинг не выпускает исходящие соединения;
  напишите в поддержку hoster.kz, попросите разрешить curl наружу.
